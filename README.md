# Проект TECH TREE

###### Technical Tree

## Описание проекта

Проект представляет собой веб-приложение с API-интерфейсом
и административной панелью,
предназначенное для управления сетью продажи электроники.

Реализована поддержка механизма Soft Delete для моделей

Административная панель для просмотра и редактирования записей сети продавцов.

Иерархия поставщиков с уровнями от завода до индивидуального предпринимателя.

Возможность создавать объекты каждого типа (заводы, сети магазинов,
индивидуальные предприниматели).

CRUD API с ограничением обновления задолженности через интерфейс API.

Фильтрация и сортировка данных.

Права доступа к API только для активных сотрудников.

## Установка и настройка

### Установка с использованием virtualenv:

python3 -m venv env

source env/bin/activate # Linux/MacOS

env\Scripts\activate # Windows

pip install --upgrade pip

pip install -r requirements.txt

### Установка с использованием Poetry:

poetry shell

poetry install

Запуск приложения

Для запуска сервера выполните команду:

__python manage.py runserver__

Администраторская панель доступна по адресу /admin.

Выполните миграцию базы данных:

python manage.py makemigrations

python manage.py migrate

Для заполнения базы тестовыми данными выполните команду

__python manage.py add_all_data__

Используемые зависимости указаны в файле

__requirements.txt__

Переменные используемые внутри проекта описаны в файле

__.env.sample__

Доступ к API защищён аутентификацией JWT токенов (SimpleJWT).

Доступ разрешен только активным сотрудникам.

### Тестирование

Тестовые сценарии покрывают функциональность проекта.

Для запуска тестов используйте команду

__python manage.py test__
